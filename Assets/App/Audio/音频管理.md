# 音频管理

路径：`Assets/App/Audio/`  
命名空间：`App.Audio`

全局 BGM 与音效由 `IAudioService` 统一播放，开关各自落盘（`audio.bgm.enabled.v1` / `audio.sfx.enabled.v1`）。
界面上不要自己挂 `AudioSource`，按钮点击音走 `PlayUiClick()`。

## 文件

| 文件 | 职责 |
|------|------|
| `IAudioService.cs` | 开关、播放、`PreloadUiClickAsync`、`ISaveFlushable` |
| `AudioService.cs` | 在宿主物体下挂 BGM / SFX 两个 2D `AudioSource` |

启动时 `AppBootstrap` 在 `SaveFramework.Create()` 之后创建服务并 `Load()`，再 `await PreloadUiClickAsync(resources)`。

## 用法

```csharp
var audio = AppServices.Resolve<IAudioService>();

audio.SetBgmEnabled(true);
audio.SetSfxEnabled(false);
audio.PlayBgm(clip, loop: true);
audio.StopBgm();
audio.PlaySfx(clip, 0.8f);
audio.PlayUiClick();
```

## 资源

- 点击音：`ResResourcePaths.SfxUiClick` = `Audio/Effect/ui_click_03`（`Assets/Res/Audio/Effect/`）
- BGM：按项目需要放到 `Assets/Res/Audio/BGM/`，key 为相对 `Assets/Res` 的无扩展名路径

点击音缺失时 `PreloadUiClickAsync` 只打一条 `AppLog.Warn(LogChannel.Assets, ...)`，不会阻断启动，
所以新工程可以先不配音频资源。

## 开关落盘

`SetBgmEnabled` / `SetSfxEnabled` 改完会标脏，`Flush()`（以及 `AppServicesHost` 在
暂停 / 失焦 / 退出时调用的 `FlushAll()`）写回 `ISaveService`。
